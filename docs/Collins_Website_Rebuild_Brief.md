# COLLINS EQUIPMENTS LLC
## Website Rebuild Brief for Web / Development Team
Prepared August 2026 | Target site: collinscouae.com | Design reference: spheavyrental.ae

## 1. Project Overview
Collins Equipments LLC is rebuilding its website. The new site should keep the existing content and equipment catalog structure, but be redesigned visually in the style of spheavyrental.ae (S&P Heavy Machinery) bold industrial layout, strong typography, dark/light contrast sections a proper sales/inquiry flow instead of static listing pages. Both Collins branch locations must be featured.

**Objective**
*   Rebuild collinscouae.com with the same core content (equipment catalog, company info, services) it has today.
*   Redesign the visual system to match the structure, layout patterns, and color palette of the reference sites (spheavyrental.ae primarily; retain elements of Collins' current identity for brand continuity).
*   Add a real sales/inquiry conversion flow: lead capture forms, a dedicated 'Request a Quote' page, per-product Buy/Rent enquiry -not just a WhatsApp link on static listing pages.
*   Showcase both Collins branch locations (address, map, contact per branch).

**Reference Sites**
*   Design/UX/layout reference: https://spheavyrental.ae/
*   Content/structure baseline (site being rebuilt): https://collinscouae.com/

## 4. New Functional Requirements - Sales / Inquiry Flow
The current site's only conversion path is a WhatsApp deep link on every "GET QUOTE" button and a generic contact form buried on each product page. The rebuild should add a proper lead-generation flow, modeled on how spheavyrental.ae handles it.

### 4.1 Homepage lead capture
*   Add a full inline lead form on the homepage itself (First Name, Last Name, Email, Phone, Message) not just a WhatsApp button matching SP's "Get In Touch" homepage section.

### 4.2 Dedicated "Request a Quote" page
*   New page, linked from primary nav and every product page CTA.
*   Mirror SP's contact page pattern: "Get our catalog and pricing - just fill out the form!", with an equipment-category dropdown and quantity/duration fields.
*   Offer a downloadable catalog/price list as a lead magnet if the client has one.

### 4.3 Per-product Buy vs. Rent flow
*   Since Collins offers both Trading (sale) and Rental for the same equipment, each product page should have a clear toggle or two distinct CTAs: "Enquire to Buy" and "Enquire to Rent" the current site has one generic "Submit Enquiry" with no way to indicate intent.
*   Carry the equipment name and selected intent (buy/rent) into the form automatically (pre-filled), rather than the generic dropdown used today.

### 4.4 Always-on contact affordances
*   Floating WhatsApp button (bottom right) - already exists, retain.
*   Add a floating Call button alongside it (SP reference uses two stacked circular buttons: orange phone icon + green WhatsApp icon).

### 4.5 Branch showcase (NEW)
*   Add a "Our Branches" section/page featuring both locations side by side: address, embedded map, phone number, and hours per branch.
*   Branch 1: Ras Al Khor 2, Dubai, UAE (confirmed, currently live).
*   Branch 2: TBD placeholder card until client provides the address.
*   Consider a location switcher or both-branches-shown-together pattern on the Contact page, rather than the current single-address block.

### 5.4 UI / Component Style (from SP reference)
*   Full-bleed dark (black) hero sections with a high-contrast background photo (sunset/dusk equipment shots) and large condensed-caps headline text.
*   Alternating black and white full-width sections down the page (not boxed/card-heavy layouts).
*   Primary CTA buttons: solid yellow fill, black bold caps text, no rounded corners (sharp/square).
*   Secondary CTA buttons: transparent/outline with colored border (orange or white), same bold caps text.
*   Short yellow underline rule beneath footer column headings ("SERVICES", "QUICK LINKS", "SOCIAL").
*   Two stacked circular floating action buttons bottom-right: phone (orange) above WhatsApp (green).
*   Inline lead-capture form embedded directly in page content (not only a separate contact page) dark background, white-bordered input fields, bold yellow submit button.

### 5.5 Imagery Style
*   Real on-site / on-jobsite photography of equipment (matches Collins' current approach) rather than stock render graphics.
*   SP reference leans into dramatic sunset/dusk silhouette shots for hero banners consider 1-2 hero images in this style for Collins, alongside existing daylight product photography.

### 5.6 Voice & Tone
*   Direct, benefit-led headline copy paired with a short reassurance line e.g. "Reliable Generators | Uninterrupted Energy For Your Critical Work." Keep this pattern; it already matches the SP reference's tone.
*   Keep the personal "Owner Message" on About Us - this kind of founder-voice content is a trust signal SP's site does not have, and is worth preserving as a differentiator.
